# Сервис управления локальной инфраструктурой

<!-- инструкции для агента -->

## Структура

```
.
├── AGENTS.md # инструкции для ИИ модели
├── app # католог бизнес логики написаной на golang
├── cmd
│   ├── atlas # main файл платформы с DI инициализацией
│   └── atlas-runner # main файл агента выполнения команд на сервере
├── go.mod
├── go.sum
├── pkg # изолированные плагины
│   ├── <plugin>
│   │   ├── service.go # бизнес логика плагина
│   │   ├── repository.go # логика работы с базой данных
│   │   └── entity.go # модели базы данных
│   └── plugins.go # общий контейнер DI для плагинов pkg
└── web # UI интерфейс сервиса на react

```
